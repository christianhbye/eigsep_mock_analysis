# C51 phase-one map accounting

This research module reconstructs the exact sky map used by034 and measures
signed conditional compact-source coefficients under the three reviewed local
backgrounds. It performs no SHT, antenna/terrain simulation, calibrated-data fit,
source correction or phase-two adoption. `REVIEWED_C51_SPEC.md` is the unchanged
reviewed two-phase specification; only phase one is implemented here.

`frozen_inputs.json` records eight necessary input identities and the readiness
check's31 small-file pins. The303MB parent hash comes from034 provenance and the
previous independent two-host audit. Each actual run recomputes all eight hashes.
Use a separate private snapshot with the listed relative paths; original data
and Astropy caches remain read-only. Never sync a protected model environment.

Create this worktree's own `.venv` with `requirements-map.txt`. The installed
pygdsm1.7.0 sources must match their audited hashes. The original map call uses
float32 NSIDE1024 Galactic/RING K_CMB, PCHIP, no CMB addition, then float32
`ud_grade(hi,64)` and `ud_grade(m64,8)` **before** float64 archive promotion.
The unit derivative is cross-checked against Planck and the actual loader helper.

From this repository root, after resource/input/runtime review:

```
uv run --no-project --python .venv/bin/python python -m compact_source_d5.preflight \
  --inputs PRIVATE_SNAPSHOT --out NEW_PREFLIGHT.json
uv run --no-project --python .venv/bin/python python -m compact_source_d5.run \
  --inputs PRIVATE_SNAPSHOT --out NEW_REPRODUCTION --stage reproduce
uv run --no-project --python .venv/bin/python python -m compact_source_d5.run \
  --inputs PRIVATE_SNAPSHOT --out NEW_ACCOUNT --stage account \
  --reproduction NEW_REPRODUCTION
```

These are separate root-gated stages. The first science stage is only109.375MHz
reproduction. The account stage streams70.3125,109.375,148.4375MHz and requires a
verified reproduction product from the same input/source/runtime identities.
Do not launch either stage solely because its command is documented.
The producer uses a new private offline Astropy cache under each output,
with internet disabled and the resolved copied parent hash checked. That cache
is expendable and excluded from the portable product manifest.

For each CygA/VirA/CasA/TauA/HerA patch, the fixed nominal56arcmin Gaussian has5deg
support and a discrete solid-angle integral of one. This is a **conditional
sensitivity model**, not a measured PSF or a bounded family of true responses.
Sparse RING-to-NESTED ancestry performs exact pixel-mean degradation without
SHTs or storing another full-resolution profile sphere. Profiles, original patch
pixel IDs, source anchors/frames, neighbour masks, fit masks, compact term,
background, model and residual are saved at1024/64/8.

The original3deg aperture/4–8deg annulus check remains unmasked. The8deg
constant+gradient and10deg quadratic models mask5deg support around the other
four pinned source anchors. This finite external list is not a complete survey
of compact regions in CygnusX. No new mask is selected using a night residual.
Too few coarse pixels or a rank-deficient design remains an unsupported row,
not a dropped frequency or zero coefficient.

Each supported background has a noiseless functional injection check, with the
reviewed1% recovery acceptance; normalization/degradation must also conserve1%.
These checks do not validate the real diffuse-background model. Synthetic math
checks live entirely here, while code/notebook057 only reads saved products.

Negative formal flux remains signed. Residual map scatter is never interpreted
as radiometer noise, a pixel-independent source error or a confidence interval.
The range across backgrounds is labelled a conditional formal span. A physical
nonnegative compatible interval remains unavailable until the response and
background envelope have independent support. All products explicitly keep
`phase2_source_replacement_allowed=false`; no map is removed/replaced here.
PB17 coefficients are evaluated only within their published domain; CasA/HerA
below200MHz remain unsupported catalogue comparisons. Epoch, polarization,
extent, coefficient covariance and correlated scale-error limits are retained.

`PRODUCT.json` binds payload hashes to an actual source snapshot, Git/runtime
identity, and immutable inputs. Historical products retain their own producer.
`RUN_STARTED.json`/`RUN_FAILED.json` preserve partial execution; an external
resource-capped launcher must also record kernel/time-limit termination.
Figures are regenerated by this module from native patch values; map/model
panels share a color scale and residuals use a signed scale. Each has a caption.
